# Facebook Autoposter

A Node.js MVP for auto-posting images to Facebook Pages.

## Features

- Facebook OAuth
- Fetch managed Pages
- Upload images to Cloudinary
- Schedule Facebook Page image posts
- Publish now
- Retry failed posts up to 3 times

## Requirements

- Node.js 18+
- MongoDB
- Cloudinary account
- Meta developer app
